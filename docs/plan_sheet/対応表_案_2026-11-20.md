## 写さない

- **発売日**: 変えると NP がタスクの日程を計算し直すため。違っていたらカルテに「スプシと違う」と出すだけ
- **★商品（商品名）**: NP は社内呼称だけを持つ（N-6-2）
- **進捗状況（チェックリスト）**: タスクの正本は NP
- **④資材の「仕入れ先の探し方」から下**: **仕入れサイトのログイン ID とパスワードが平文で入っている**（テンプレートなので全商品のスプシに複製される）。NP は読まない。範囲を番地で切る
- ①・⑤・⑬ の **AI への指示文**（プロンプト）: 答えのセルだけを写す。指示文を写すと、カルテを読む NP の AI に指示として渡ってしまう
- ⑭商品改訂履歴（NP の履歴が正本）・【LP依頼用】チェックリスト・M_商品タイプ定義
